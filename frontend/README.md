# Frontend (React + TypeScript)

SPA para registro y listado de pacientes.

## Estructura

```
src/
├── components/
│   ├── common/       # Button, Modal, Spinner, etc.
│   ├── patients/     # PatientCard, PatientList
│   └── forms/        # PatientForm, DragDropInput
├── hooks/            # usePatients, etc.
├── services/         # API client
├── types/            # Patient, ApiError, etc.
└── styles/           # Variables y estilos globales
```

## Scripts

```bash
npm install
npm run dev
npm run lint
npm run format
```
